Style Tile

This page documents the design choices used for Haunting of Virginia, including the colors, typography, and spacing.

Palette

Primary: Dark Purple #241f2f. Used for the header background.

Neutral: Near-Black #262220. Used for body text.

Accent: Muted Burnt Orange #a05235. Used for highlights and design details.

CTA: Dark Burnt Orange #8b3f24. Used for the main call-to-action button.

Type Scale

Heading 1, 2.5rem (40px)

Heading 2, 1.75rem (28px)

Heading 3, 1.25rem (20px)

Body text, 1rem (16px)

Spacing

  • Main content: max-width 800px, centered with margin 0 auto, padding 40px top and bottom, 20px left and right.
  • Headings: margin-bottom 8px.
  • Paragraphs: margin-bottom 32px.
  • Call-to-action button: padding 16px top and bottom, 32px left and right, with margin-top 24px.
